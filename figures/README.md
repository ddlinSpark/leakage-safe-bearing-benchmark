# Figures

`figures/publication/` contains figures generated automatically from the
canonical CSV files in `results/`. Run:

```bash
spindle-statistical-analysis
spindle-publication-figures
```

No numeric values in the figures are entered by hand.

The method figures are generated separately from the experiment code and
configuration:

```bash
spindle-method-figures
```

The manuscript figure-to-script mapping is maintained in
[`docs/paper/FIGURE_SOURCES.md`](../docs/paper/FIGURE_SOURCES.md).
