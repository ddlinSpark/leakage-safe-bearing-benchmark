# 本地归档说明

以下内容保留在本机，但不进入 Git：

| 路径 | 内容 |
| --- | --- |
| `data/` | 原始传感器与事件数据 |
| `dataset_final/` | 清洗后数据表、滑窗索引和预览图 |
| `outputs/` | 训练输出、模型权重、指标和缓存 |

| `artifacts/local/` | 比赛投稿副本、压缩包、旧提取特征 |

因此只保留一份可维护代码。投稿目录中的模型、测试报告和数据仍作为本地成果
归档保留。

如远程仓库需要发布少量结果图，可使用 Git LFS 或 GitHub Release；不要把完整
数据集、权重目录或比赛压缩包直接提交到普通 Git 历史。
