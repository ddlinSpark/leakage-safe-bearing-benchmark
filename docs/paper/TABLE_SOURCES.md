# Manuscript Table Sources

The manuscript builder loads every experimental value from the canonical result
files. No result table is populated by hand.

## Table 1: Bearing-code-disjoint and condition-disjoint folds

- Builder function: `fold_rows()` in
  `src/spindle_cnn/paper/build_docx.py`.
- Sources: `results/splits/fold0.json` through `results/splits/fold3.json`.
- Related protocol metadata: `configs/paderborn_main.json` and
  `data/public/paderborn/pu_4class_w8192.json`.
- Derived fields: training, validation, and test condition labels; partition
  window counts; held-out record IDs.

## Table 2: CWT-GRU tensor flow and layer parameters

- Builder: `src/spindle_cnn/paper/build_docx.py`.
- Sources: `src/spindle_cnn/models/layers.py`,
  `src/spindle_cnn/models/cwt_gru.py`, and
  `src/spindle_cnn/public_benchmark/pu_data.py`.
- Tensor shapes are also checked against the metadata in
  `data/public/paderborn/pu_4class_w8192.json`.

## Table 3: Canonical training configuration

- Builder: `src/spindle_cnn/paper/build_docx.py`.
- Sources: `configs/paderborn_main.json`,
  `src/spindle_cnn/training/runner.py`,
  `src/spindle_cnn/evaluation/calibration.py`, and
  `results/runs/<run_id>/config.json`.
- The device name is read from a retained run configuration rather than entered
  as prose.

## Table 4: Canonical experiment matrix

- Builder: `src/spindle_cnn/paper/build_docx.py`.
- Sources: `results/raw_runs.csv` and `configs/paderborn_main.json`.
- Run counts are computed by grouping `experiment_type`; method, fold, seed, and
  threshold counts are validated by `src/spindle_cnn/paper/data.py`.

## Table 5: Full-label model comparison

- Builder function: `main_table_rows()`.
- Sources: `results/summary_with_ci.csv` and `results/raw_runs.csv`.
- Displayed values: mean, sample standard deviation, and number of matched
  evaluations for every main method condition.

## Table 6: Paired comparisons against Raw 1D-CNN

- Builder function: `paired_rows()`.
- Sources: `results/statistical_tests.csv` and `results/raw_runs.csv`.
- Pairing keys: identical `fold` and `seed`. The table reports the paired mean
  difference, 95% bootstrap interval, and two-sided Wilcoxon p value.

## Table 7: Label efficiency

- Builder function: `label_rows()`.
- Sources: `results/label_efficiency_summary.csv`,
  `results/statistical_tests.csv`, and the label-efficiency rows in
  `results/raw_runs.csv`.
- The 100% condition reuses the canonical main rows; it is not a separate
  training count.

## Table 8: Pseudo-label confidence-threshold sensitivity

- Builder function: `threshold_rows()`.
- Sources: `results/threshold_summary.csv` and the threshold rows in
  `results/raw_runs.csv`.
- The table reports pseudo-label count, candidate coverage, offline
  pseudo-label accuracy, test macro-F1, and run count.

## Table 9: Probability calibration

- Builder function: `calibration_rows()`.
- Sources: `results/raw_runs.csv`, columns `raw_ece`, `ece`, `raw_nll`, `nll`,
  `raw_brier`, and `brier`.
- Values are means over the 20 main evaluations for each selected model.

## Table 10: Models eligible for same-protocol comparison

- Builder function: `sota_rows()`.
- Sources: `results/summary_with_ci.csv`,
  `results/raw_runs.csv`, and the architecture registry under
  `src/spindle_cnn/models/`.
- Parameter values are medians of the recorded parameter counts.
- No unreproduced external model or published cross-protocol value appears in
  the table.

## Table 11: Component-wise ablation

- Builder function: `ablation_rows()`.
- Sources: `results/ablation_summary.csv`,
  `results/summary_with_ci.csv`, and corresponding main rows in
  `results/raw_runs.csv`.
- The component flags are generated by
  `src/spindle_cnn/analysis/statistics.py`.

## Table 12: Computational cost

- Builder function: `complexity_rows()`.
- Primary source: the main-experiment rows in `results/raw_runs.csv`, grouped by
  method in `BenchmarkResults.main_cost()`.
- Cross-check: `results/model_complexity.csv`, which aggregates all experiment
  types and is used for the computational-cost figure.
- Training time includes the full training process for each main condition.
  Inference time is measured per test batch and is hardware-dependent.

## Reproduction check

Run the manuscript tests and rebuild command in
`PAPER_REPRODUCIBILITY.md`. The builder fails if a required source row is
missing, a canonical run is unsuccessful, a run ID is duplicated, or a method
does not have the required repetition count.
